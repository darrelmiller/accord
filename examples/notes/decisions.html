Save contract

Save replaces only changed text ranges and assigns missing block IDs. Unchanged source, links, assets, comments, and metadata remain untouched.

When disk content changes

A stale save is rejected. Copy unsaved text before explicitly reloading; this prototype does not merge changes.

Use a source editor for structure

Adding sections, formatting, links, tables, or images is outside this text-only authoring slice.
